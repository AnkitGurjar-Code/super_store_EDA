# Super Store Sales Analysis 📊

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of Super Store sales data to understand sales performance, customer behavior, product performance, regional trends, and profitability.

The dataset contains 9,994 records and 21 columns covering order details, customer information, shipping mode, segment, region, product category, sub-category, sales, quantity, discount, and profit.

The project follows a structured data analysis workflow using Python, Pandas, and data visualization techniques to transform raw transactional data into meaningful business insights.

---

## 🎯 Business Objective

The objective of this project is to analyze Super Store sales data and identify meaningful patterns and relationships across customers, products, categories, regions, sales, discounts, and profit.

The analysis aims to identify areas of strong business performance as well as opportunities for improving sales and profitability.
